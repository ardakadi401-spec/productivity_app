## Data Safety Form — Hazırlık Notları

Play Console'un "Veri Güvenliği" formunu doldururken (form Console arayüzünde doldurulur, bu bölüm yalnızca doğru cevapları vermen için referanstır):

| Soru | Cevap | Gerekçe |
|---|---|---|
| Veri topluyor musunuz? | Evet | E-posta, ad, kullanıcı içeriği (bkz. Privacy Policy §2) |
| Veri paylaşıyor musunuz? | Hayır | Yalnızca Firebase altyapısı (§4), üçüncü taraf paylaşım yok |
| Veriler şifreli mi aktarılıyor? | Evet | Firebase SDK varsayılan olarak TLS kullanır |
| Kullanıcı veri silme talep edebiliyor mu? | Evet | Ayarlar → Hesabı Sil (uygulama içi, anlık) |
| Reklam kimliği (Advertising ID) toplanıyor mu? | Hayır | Reklam SDK'sı yok |
| Konum verisi toplanıyor mu? | Hayır | — |
| Finansal bilgi toplanıyor mu? | Hayır | Ödeme/satın alma özelliği yok |
| Sağlık/fitness verisi toplanıyor mu? | Hayır | — |

**Toplanan veri kategorileri (Console formunda işaretlenecek):**
- Kişisel bilgiler → E-posta adresi, Ad
- Uygulama etkinliği → Uygulama içi eylemler (görev/not/alışkanlık verisi — "kullanıcının oluşturduğu içerik" kategorisinde)

**Gizlilik Politikası URL'si:** yayınlanan Artifact linki (bkz. `PRIVACY_POLICY.md` başlığı) — Console'a eklemeden önce artifact'ın paylaşım menüsünden herkese açık yapılması gerekir.
